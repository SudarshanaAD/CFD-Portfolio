# NACA Airfoil Generator

## Overview
This project generates NACA 4-digit airfoil coordinates using Python and visualizes the airfoil geometry.

The code computes the thickness distribution and creates the upper and lower surface coordinates of a NACA airfoil profile.

## Features

- Generate NACA 4-digit airfoils
- Compute thickness distribution
- Generate upper and lower surface coordinates
- Visualize airfoil geometry using Matplotlib
- Simple and beginner-friendly implementation

## Technologies Used

- Python
- NumPy
- Matplotlib
